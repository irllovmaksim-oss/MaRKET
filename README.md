# TechMarket — Интернет-магазин электроники

## Описание проекта
TechMarket — учебный проект интернет-магазина электроники с персональной системой рекомендаций товаров.

## Основные возможности
- Просмотр каталога товаров.
- Поиск и фильтрация товаров.
- Добавление товаров в корзину.
- Оформление заказов.
- Персональные рекомендации.
- Подбор похожих и сопутствующих товаров.

## Материалы проекта
1. Документация и отчёт.
2. База данных товаров и покупателей.
3. Три алгоритма рекомендаций.
4. Пять пользовательских сценариев.
5. Архитектура системы.
6. ER-диаграмма.
7. Три диаграммы последовательности.
8. Десять тестовых сценариев.
9. Прототип интерфейса в Figma.

## Используемые инструменты
- Figma — проектирование интерфейса.
- draw.io — создание диаграмм.
- Excel — подготовка данных.
- GitHub — хранение и управление файлами проекта.
